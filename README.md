# 어랍쇼 GitHub Pages 검토본

청소년기관 현장실습 업무를 준비·운영·평가하는 담당자를 위한 정적 웹 안내서입니다.

## 구성

- `index.html`: 웹 안내서 본문(V3.1, 2026-11-26 개정)
- `온라인전환안내.md`: 정적 검토본에서 공동 운영 시스템으로 전환하기 위한 기준
- `.nojekyll`: GitHub Pages에서 Jekyll 변환 없이 정적 파일을 그대로 배포하기 위한 표시 파일

현재 자료에는 참여기관 6개, 안내 서식 43종, 내장 HWPX 11종, 매뉴얼 23개 장이 포함되어 있습니다.

## GitHub Pages 배포

1. 이 폴더의 파일을 저장소의 배포 브랜치 루트 또는 `/docs` 폴더에 업로드합니다.
2. 저장소의 `Settings > Pages`에서 `Deploy from a branch`를 선택합니다.
3. 배포 브랜치와 폴더(`/` 또는 `/docs`)를 지정하고 저장합니다.
4. 배포가 완료되면 발급된 주소에서 홈·업무흐름·서식·매뉴얼·기관별 공간·소통게시판·즐겨찾기·자료관리·담당자 관리 화면을 확인합니다.

공식 안내: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 공개 전 필수 확인

- GitHub Pages는 정적 호스팅입니다. 게시글·체크리스트·즐겨찾기·교체 자료는 브라우저별 저장소에만 보관되며 다른 사용자와 공유되지 않습니다.
- 담당자 관리 화면의 비밀번호와 테스트 접속은 UI 검토용일 뿐 실제 인증·권한 통제가 아닙니다.
- 실습생 개인정보, 연락처, 이력서, 평가자료 등 실제 개인정보를 이 검토본에 입력하거나 저장소에 업로드하지 않습니다.
- 공개 운영 전에는 담당자 관리 메뉴를 비활성화하거나 별도의 인증 서버를 연결합니다.
- 공동 사용이 필요하면 API·데이터베이스·권한 관리·파일 검사·감사기록·백업 체계를 구축합니다.

## 검토 권장 순서

1. 데스크톱과 모바일에서 화면 배치 확인
2. 9개 주요 메뉴와 검색·필터·즐겨찾기·백업 기능 확인
3. 서식 43종과 HWPX 11종의 구분 확인
4. 실습 운영 기준·서식 문구의 최종 업무 검토
5. 공개 범위와 개인정보 처리 기준 확정
6. 정적 검토본 공개 또는 온라인 시스템 개발 여부 결정
